# CUE public build snapshot

The owner authorized this public copy to compile CUE with standard free GitHub-hosted macOS runners. The original repository remains private. This copy contains the reviewed current application source without original Git history, personal documents or private signing material. BUILD_SOURCE.json identifies the input source and archive checksum.

The iPhone workflow is manual-only and uses the standard macos-15 and macos-15-intel runners, not paid larger runners. The resulting unsigned ARM64 device IPA is for Sideloadly signing. Complete native checks are enabled by default. No payment, model API key, app account or cloud inference is required for CUE.

The application's original third-party notices and permanent free/local-only product requirement are retained. This is source/build evidence, not a claim of physical iPhone 16e validation.
